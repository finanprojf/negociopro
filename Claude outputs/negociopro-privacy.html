Política de Privacidad — NegocioPro

Última actualización: 11 de septiembre de 2026

Esta Política de Privacidad describe cómo FinanPro Solutions recopila, usa y protege la información en la aplicación NegocioPro, diseñada para la gestión inteligente de negocios (inventario, ventas, clientes, gastos y más).

1. Información que Recopilamos

  • Datos de cuenta: correo electrónico y contraseña (almacenada de forma cifrada).
  • Datos del negocio: nombre del negocio, productos, categorías, precios, stock, ventas, gastos, clientes y encargos que el usuario ingresa voluntariamente.
  • Datos de clientes del negocio: nombres, teléfonos y notas ingresados por el usuario para gestionar fiados y encargos.

2. Cómo Usamos la Información

La información recopilada se usa exclusivamente para:

  • Proveer las funciones de gestión de inventario, punto de venta, clientes y reportes.
  • Autenticar al usuario y sincronizar datos entre dispositivos.
  • Permitir el funcionamiento sin conexión a internet mediante almacenamiento local.

No vendemos, alquilamos ni compartimos su información con terceros.

3. Almacenamiento de Datos

  • Local: los datos se guardan en el dispositivo del usuario para permitir acceso sin internet.
  • Nube: se usa Supabase para respaldo seguro y sincronización entre dispositivos.

4. Seguridad

Implementamos medidas de seguridad que incluyen:

  • Cifrado de contraseñas.
  • Conexiones HTTPS para toda comunicación con la nube.
  • Acceso a datos restringido por empresa/usuario autenticado.

Aunque tomamos medidas razonables, ningún sistema es 100 % seguro.

5. Responsabilidad del Usuario

El usuario es responsable de obtener el consentimiento necesario de sus clientes para registrar sus datos en la aplicación, conforme a las leyes de protección de datos aplicables en su país.

6. Eliminación de Datos

El usuario puede eliminar su cuenta y todos los datos asociados contactándonos en finanprojf@gmail.com. La eliminación es permanente e irreversible.

7. Permisos de la Aplicación

NegocioPro puede solicitar los siguientes permisos:

  • Cámara: para escanear códigos de barras y tomar fotos de productos.
  • Almacenamiento: para guardar imágenes de productos.
  • Bluetooth: para impresión térmica de recibos.
  • Internet: para sincronización con la nube.

8. Cambios a Esta Política

Podemos actualizar esta política ocasionalmente. Notificaremos cambios importantes dentro de la aplicación. El uso continuo de NegocioPro después de los cambios implica aceptación de la nueva política.
